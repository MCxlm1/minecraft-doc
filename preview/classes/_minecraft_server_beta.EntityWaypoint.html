类 EntityWaypoint

跟踪实体位置的路径点。该路径点会随着实体的移动自动更新，并在实体被移除时失效。

constructor

  • new EntityWaypoint(entity, textureSelector, entityRules, color?): EntityWaypoint

  • 参数

    • entity: Entity

      要跟踪的实体。

    • textureSelector: WaypointTextureSelector

      用于选择路径点纹理的纹理选择器。

    • entityRules: EntityVisibilityRules

      控制路径点基于实体状态显示的可见性规则。

    • 可选color: RGB

      路径点的可选颜色。

    返回 EntityWaypoint

属性

可选color

color?: RGB

备注

可选的 RGB 颜色色调，应用于路标点图标。若未指定，路标点将使用其默认颜色。

This property can't be edited in restricted-execution mode.

备注

控制路径点何时显示的可见性规则，具体基于实体的状态（例如潜行、隐身、死亡）。

InvalidWaypointError

isEnabled

isEnabled: boolean

备注

控制路标点当前是否显示在玩家的屏幕上。禁用时，路标点会被隐藏，但仍保持有效。

This property can't be edited in restricted-execution mode.

继承自 Waypoint.isEnabled

只读isValid

isValid: boolean

备注

返回路标点当前是否有效。当所追踪的实体不再有效时，路标点将变为无效。

继承自 Waypoint.isValid

textureSelector

textureSelector: WaypointTextureSelector

备注

用于根据距离或其他条件决定路标点显示哪种图标纹理的 WaypointTextureSelector。

This property can't be edited in restricted-execution mode.

继承自 Waypoint.textureSelector

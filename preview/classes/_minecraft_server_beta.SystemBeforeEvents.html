类 SystemBeforeEvents

一组在实际动作发生之前触发的事件。 在大多数情况下，你有可能取消或修改 即将发生的事件。请注意，在 before 事件中， 任何修改游戏状态的 API 都不会生效， 并且会抛出错误。

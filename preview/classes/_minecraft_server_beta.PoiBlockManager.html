方法

addTemporary

  • addTemporary(position, poi): void

  • 参数

    • position: Vector3

      要添加 POI 的方块位置。

    • poi: string | number | PoiBlockType

      要添加的 POI 类型，可通过数字类型 ID、类型名称或 POI 类型对象指定。

    返回 void

    备注

    在指定位置添加一个方块兴趣点。此方法用于临时用途，将在区块重新加载时被替换。

    Privilege

    no-restricted-execution - 此函数不能在受限执行模式下调用。

at

  • at(position): PoiBlockType

  • 参数

    • position: Vector3

      要检查的方块位置。

    返回 PoiBlockType

    该位置的 POI 类型；如果该位置不存在 POI，则返回 undefined。

    备注

    获取某个位置上方块兴趣点的类型。

    Privilege

    no-restricted-execution - 此函数不能在受限执行模式下调用。

exists

  • exists(position, filter): boolean

  • 参数

    • position: Vector3

      要检查的方块位置。

    • filter: ((arg0: PoiBlockType) => boolean) | PoiNameFilter | PoiTagFilter

      用于选择 POI 类型的过滤器。回调函数接收 POI 类型并返回是否匹配；名称过滤器匹配类型名称；标签过滤器要求满足所有指定标签。

    返回 boolean

    如果该位置存在 POI 且其类型与过滤器匹配，则返回 true；否则返回 false。

    备注

    测试某个位置上方块兴趣点是否与类型过滤器匹配。

    Privilege

    no-restricted-execution - 此函数不能在受限执行模式下调用。

getInRange

  • getInRange(filter, center, blockRadius, occupancyFilter?): PoiBlockInstance[]

  • 参数

    • filter: PoiNameFilter | PoiTagFilter | ((arg0: PoiBlockType) => boolean)

      用于选择 POI 类型的过滤器。回调函数接收每个 POI 类型并返回是否应包含；名称过滤器匹配类型名称；标签过滤器要求满足所有指定标签。

    • center: Vector3

      搜索中心。

    • blockRadius: number

      距中心的最大三维距离，以方块为单位。

    • 可选occupancyFilter: PoiBlockOccupancyFilter

      可选的占用状态过滤器，应用于匹配的 POI。如果省略，则返回任何占用状态的 POI。

    返回 PoiBlockInstance[]

    范围内匹配的 POI 实例。结果顺序不保证。

    备注

    返回指定位置指定距离内与所提供的类型和占用状态过滤器匹配的方块兴趣点。

    Privilege

    no-restricted-execution - 此函数不能在受限执行模式下调用。

getInRangeSorted

  • getInRangeSorted(filter, center, blockRadius, occupancyFilter?): PoiDistancePair[]

  • 参数

    • filter: PoiNameFilter | PoiTagFilter | ((arg0: PoiBlockType) => boolean)

      用于选择 POI 类型的过滤器。回调函数接收每个 POI 类型并返回是否应包含；名称过滤器匹配类型名称；标签过滤器要求满足所有指定标签。

    • center: Vector3

      搜索中心以及计算距离的位置。

    • blockRadius: number

      距中心的最大三维距离，以方块为单位。

    • 可选occupancyFilter: PoiBlockOccupancyFilter

      可选的占用状态过滤器，应用于匹配的 POI。如果省略，则返回任何占用状态的 POI。

    返回 PoiDistancePair[]

    匹配的 POI 实例及其与中心的平方距离，按距离升序排序。

    备注

    返回与所提供的类型和占用状态过滤器匹配的方块兴趣点，这些兴趣点位于以指定位置为中心的轴对齐正方形内，并按从近到远排序。

    Privilege

    no-restricted-execution - 此函数不能在受限执行模式下调用。

getInSquare

  • getInSquare(filter, center, blockRadius, occupancyFilter?): PoiBlockInstance[]

  • 参数

    • filter: PoiNameFilter | PoiTagFilter | ((arg0: PoiBlockType) => boolean)

      用于选择 POI 类型的过滤器。回调函数接收每个 POI 类型并返回是否应包含；名称过滤器匹配类型名称；标签过滤器要求满足所有指定标签。

    返回 PoiBlockInstance[]

    搜索体积内匹配的 POI 实例。

    备注

    返回与所提供的类型和占用状态过滤器匹配的方块兴趣点，这些兴趣点位于以指定位置为中心的轴对齐正方形内。

    Privilege

    no-restricted-execution - 此函数不能在受限执行模式下调用。

release

  • release(center): boolean

  • 参数

    • center: Vector3

      要释放其票证的 POI 的方块位置。

    返回 boolean

    如果释放了票证，则返回 true；如果该位置不存在 POI 或该 POI 没有已领取的票证，则返回 false。

    备注

    释放一个方块兴趣点上一个先前领取的票证。

    Privilege

    no-restricted-execution - 此函数不能在受限执行模式下调用。

take

  • take(filter, center, blockRadius): Vector3

  • 参数

    • filter: PoiNameFilter | PoiTagFilter | ((arg0: PoiBlockType) => boolean)

      用于选择要领取的 POI 类型的过滤器。回调函数接收每个 POI 类型并返回是否应包含；名称过滤器匹配类型名称；标签过滤器要求满足所有指定标签。

    • center: Vector3

      搜索中心。

    • blockRadius: number

      距中心的最大三维距离，以方块为单位。

    返回 Vector3

    被领取的 POI 的方块位置；如果没有匹配的 POI 有可用票证，则返回 undefined。

    备注

    从范围内匹配的方块兴趣点中领取一个可用票证。

    Privilege

    no-restricted-execution - 此函数不能在受限执行模式下调用。

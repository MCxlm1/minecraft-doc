方法

静态createValid

  • createValid(min, max): BlockBoundingBox

  • 参数

    • min: Vector3

      一个角落的世界坐标

    • max: Vector3

      与之对角的另一个角落的世界坐标

    返回 BlockBoundingBox

    返回一个有效的 BlockBoundingBox 实例。

    备注

    创建一个经过验证的 BlockBoundingBox 实例，其中最小值和最大值分量保证满足 (min <= max)。

    This function can't be called in restricted-execution mode.

静态dilate

  • dilate(box, size): BlockBoundingBox

  • 参数

    • box: BlockBoundingBox

      要扩展的 BlockBoundingBox 对象

    • size: Vector3

      沿各轴的扩展量

    返回 BlockBoundingBox

    返回一个表示更改后的新 BlockBoundingBox 对象

    备注

    沿每个轴将 BlockBoundingBox 扩展给定的大小。 大小为负数时可进行收缩。 注意：如果收缩大小大于跨度，角落可能会反转，但最小值/最大值关系仍然正确。

    This function can't be called in restricted-execution mode.

静态expand

  • expand(box, other): BlockBoundingBox

  • 参数

    • box: BlockBoundingBox

      要扩展的边界框

    • other: BlockBoundingBox

      要包含的另一个边界框

    返回 BlockBoundingBox

    返回一个新的 BlockBoundingBox 实例，表示能同时包含两者的最小边界框。

    备注

    扩展初始边界框对象的边界以包含第二个边界框参数。 生成的 BlockBoundingBox 对象将是一个恰好能包含这两个盒子的边界框。

    This function can't be called in restricted-execution mode.

静态getCenter

  • getCenter(box): Vector3

  • 参数

    • box: BlockBoundingBox

      要计算中心的边界框

    返回 Vector3

    注意：BlockBoundingBox 对象表示整个方块，因此边界为奇数的盒子的中心在数学上并不居中…… 即 BlockBoundingBox( 0,0,0 -> 3,3,3 ) 的中心为 (1,1,1)（而不是预期的 (1.5, 1.5, 1.5)）。

    备注

    计算给定 BlockBoundingBox 对象的中心方块。

    This function can't be called in restricted-execution mode.

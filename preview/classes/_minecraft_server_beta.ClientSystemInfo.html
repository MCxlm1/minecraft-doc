locale: string

备注

客户端选择的区域设置（例如 en_US、fr_FR、ja_JP）。请注意，在大多数情况下，服务器脚本不应使用此属性手动本地化文本。相反，应使用带有 translate 字段的 RawMessage 发送本地化键，让每个客户端自动以自己的语言解析它们。直接使用区域设置进行本地化较为脆弱，并且当同一服务器上有不同语言的玩家时，可能会产生意外结果。

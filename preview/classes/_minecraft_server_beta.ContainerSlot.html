类 ContainerSlot

表示更大容器（如实体物品栏）中的一个槽位。

属性

amount

amount: number

备注

物品堆叠中的物品数量。有效值范围为 1-255。 提供的值将被限制到该物品的最大堆叠数量。

此属性无法在受限执行模式下编辑。

边界：[1, 255]

抛出

如果值超出 1-255 的范围，则抛出异常。

只读isStackable

isStackable: boolean

备注

返回该物品是否可堆叠。如果物品的最大堆叠数量大于 1， 且物品不包含任何自定义数据或属性，则该物品被视为可堆叠。

抛出

如果槽位的容器无效，则抛出异常。

InvalidContainerSlotError

只读isValid

isValid: boolean

备注

返回 ContainerSlot 是否有效。如果容器存在且已加载， 并且槽位索引有效，则容器槽位有效。

keepOnDeath

keepOnDeath: boolean

备注

获取或设置物品在死亡时是否保留。

此属性无法在受限执行模式下编辑。

抛出

如果槽位的容器无效，则抛出异常。

lockMode

lockMode: ItemLockMode

备注

获取或设置物品的锁定模式。默认值为 ItemLockMode.none。

此属性无法在受限执行模式下编辑。

抛出

如果槽位的容器无效，则抛出异常。

只读maxAmount

maxAmount: number

备注

最大堆叠数量。该值根据物品类型不同而变化。例如， 火把的最大堆叠数量为 64，而鸡蛋的最大堆叠数量为 16。

抛出

如果槽位的容器无效，则抛出异常。

InvalidContainerSlotError

可选nameTag

nameTag?: string

备注

该物品堆叠的给定名称。当光标悬停在物品上时会显示名称标签。 将名称标签设置为空字符串或 undefined 将移除名称标签。

此属性无法在受限执行模式下编辑。

抛出

如果槽位的容器无效，则抛出异常。如果名称长度超过 255 个字符，也会抛出异常。

只读type

type: ItemType

备注

物品的类型。

抛出

如果槽位的容器无效，则抛出异常。

minecraftcommon.EngineError

typeId: string

备注

该物品堆叠的类型标识符。如果未指定命名空间， 则默认为 'minecraft:'。示例包括 'wheat' 或 'apple'。

抛出

如果槽位的容器无效，则抛出异常。

InvalidContainerSlotError

类 TextPrimitive

属性

可选attachedTo

attachedTo?: Entity

备注

此形状所附加的实体。设置后，此形状将复制附加实体的根位置，而形状的位置将用作偏移量。

继承自 PrimitiveShape.attachedTo

backfaceVisible

backfaceVisible: boolean

备注

如果设置为 true，文本原始形状将渲染背景的背面。 默认为 true，但若 'useRotation' 设置为 false，则始终为 false。

可选backgroundColorOverride

backgroundColorOverride?: RGBA

备注

文本背景板的颜色。如果设置为 undefined，则使用默认颜色。

color

color: RGBA

备注

形状的颜色。

继承自 PrimitiveShape.color

depthTest

depthTest: boolean

备注

如果设置为 true，文本将被方块或实体遮挡。 默认设置为 false（始终渲染）。

只读dimension

dimension: Dimension

备注

形状可见的维度。如果维度未定义，则将在所有维度中显示。

继承自 PrimitiveShape.dimension

只读hasDuration

hasDuration: boolean

备注

如果形状在移除前具有有限的时间跨度，则返回 true。

继承自 PrimitiveShape.hasDuration

betalineGapHeight

lineGapHeight: number

备注

该值决定 TextPrimitive 的行间距。 默认行间距高度为 0。

只读location

location: Vector3

备注

形状的位置。

继承自 PrimitiveShape.location

可选maximumRenderDistance

maximumRenderDistance?: number

备注

如果定义了，此距离将用于确定每个客户端渲染此基元的距离。默认情况下，距离将与客户端的渲染距离设置匹配。

最小值：0

继承自 PrimitiveShape.maximumRenderDistance

rotation

rotation: Vector3

备注

形状的旋转（欧拉角 - [俯仰, 偏航, 翻滚]）。

继承自 PrimitiveShape.rotation

scale

scale: number

备注

形状的缩放。

范围：[-1000, 1000]

继承自 PrimitiveShape.scale

只读text

text: string | RawMessage

备注

获取调试文本形状的文本。如果 setText 是以 RawMessage 或 RawText 对象调用的，则返回相应 RawText，否则返回字符串。

textBackfaceVisible

textBackfaceVisible: boolean

备注

如果设置为 true，文本原始形状将渲染文本的背面。 默认为 true，但若 'useRotation' 设置为 false，则始终为 false。

可选timeLeft

timeLeft?: number

备注

到此形状自动移除的剩余时间（秒）。如果形状没有有限的生命周期，则返回 undefined。

继承自 PrimitiveShape.timeLeft

可选 只读totalTimeLeft

totalTimeLeft?: number

备注

到此形状自动移除的初始总时间跨度（秒）。如果形状没有有限的生命周期，则返回 undefined。

继承自 PrimitiveShape.totalTimeLeft

useRotation

useRotation: boolean

备注

如果设置为 true，文本将不会面向摄像机， 而是使用形状的旋转。

visibleTo

visibleTo: Player[]

备注

此形状可见的玩家列表。如果留空，则形状对所有玩家可见。

继承自 PrimitiveShape.visibleTo

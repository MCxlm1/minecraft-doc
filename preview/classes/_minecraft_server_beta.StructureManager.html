类 StructureManager

结构与相关 API 的管理器。包括创建、获取、放置和删除结构的 API。

createEmpty

  • createEmpty(identifier, size, saveMode?): Structure

  • 参数

    • identifier: string

      结构的名称。有效标识符必须包含命名空间且必须唯一。

    • size: Vector3

      结构的大小。例如，要创建单个方块结构，大小应为 {x:1, y:1, z:1}。

    • 可选saveMode: StructureSaveMode

      创建时结构的保存方式。默认为 StructureSaveMode.Memory。 默认值：0

    返回 Structure

    返回新创建的结构。

    备注

    在内存中创建一个空白结构。使用 Structure.setBlockPermutation 来用方块填充结构， 并通过 Structure.saveAs 保存更改。

    This function can't be called in restricted-execution mode.

    抛出

    如果标识符无效，则抛出异常。有效标识符必须包含命名空间且必须唯一。

    minecraftcommon.EngineError

    minecraftcommon.InvalidArgumentError

createFromWorld

  • createFromWorld(identifier, dimension, from, to, options?): Structure

  • 参数

    • identifier: string

      结构的名称。有效标识符必须包含命名空间且必须唯一。

    • dimension: Dimension

      从中读取方块所用的维度。

    • from: Vector3

      结构区域起始角的坐标。

    • to: Vector3

      结构区域结束角的坐标。

    • 可选options: StructureCreateOptions

      从世界创建结构时的附加选项。

    返回 Structure

    返回新创建的结构。

    备注

    从世界中的方块创建一个新结构。这在功能上等同于 /structure save 命令。

    This function can't be called in restricted-execution mode.

    抛出

    如果标识符无效，则抛出异常。有效标识符必须包含命名空间且必须唯一。 如果结构边界超过最大大小，则抛出异常。 如果结构边界包含世界边界以外的方块，则抛出异常。

    minecraftcommon.InvalidArgumentError

delete

  • delete(structure): boolean

  • 参数

    • structure: string | Structure

      要删除的结构标识符或 Structure 对象。注意，Structure 对象在删除后将失效。

    返回 boolean

    返回结构是否已被移除。

    备注

    从内存和世界（如果存在）中删除一个结构。

    This function can't be called in restricted-execution mode.

    抛出

    如果结构无法被删除，则抛出异常。例如，从行为包加载的结构。

    minecraftcommon.InvalidArgumentError

    返回 Structure

    备注

    备注

place

  • place(structure, dimension, location, options?): void

  • 参数

    • structure: string | Structure

      结构的标识符或 Structure 对象。

    • dimension: Dimension

      应放置结构的维度。

    • location: Vector3

      维度中应放置结构的位置。

    • 可选options: StructurePlaceOptions

      结构放置的附加选项。

    返回 void

    备注

    在世界中放置一个结构。放置在未加载区块中的结构将加入加载队列。

    This function can't be called in restricted-execution mode.

    抛出

    如果完整性值超出 [0,1] 范围，则抛出异常。 如果完整性种子无效，则抛出异常。 如果放置位置包含世界边界以外的方块，则抛出异常。

    minecraftcommon.ArgumentOutOfBoundsError

    minecraftcommon.InvalidArgumentError

    InvalidStructureError

placeJigsaw

  • placeJigsaw(pool, targetJigsaw, maxDepth, dimension, location, options?): BlockBoundingBox

  • 参数

    • pool: string

      起始模板池的标识符。

    • targetJigsaw: string

      起始拼图方块的名称。该方块必须包含在起始模板池的至少一个结构模板中。

    • maxDepth: number

      拼图结构的最大递归深度。 范围：[1, 20]

    • dimension: Dimension

      放置拼图结构所在的维度。

    • location: Vector3

      拼图结构相对于 targetJigsaw 方块开始生成的位置。

    • 可选options: JigsawPlaceOptions

      生成拼图结构时可选的设置。

    返回 BlockBoundingBox

    返回一个 BlockBoundingBox 对象，表示拼图结构的最大边界。

    备注

    在世界中放置部分拼图结构。这对于调试拼图方块之间的连接非常有用。

    This function can't be called in restricted-execution mode.

    抛出

    如果 maxDepth 超出 [1,20] 范围，则抛出异常。 如果由于无效参数或拼图配置导致生成失败，则抛出异常。 如果放置位置包含世界边界以外的方块，则抛出异常。

    PlaceJigsawError

placeJigsawStructure

  • placeJigsawStructure(identifier, dimension, location, options?): BlockBoundingBox

  • 参数

    • identifier: string

      拼图结构的标识符。

      放置拼图结构所在的维度。

    • 可选options: JigsawStructurePlaceOptions

      生成拼图结构时可选的设置。

    返回 BlockBoundingBox

    返回一个 BlockBoundingBox 对象，表示拼图结构的最大边界。

    备注

    在世界中放置一个拼图结构。

    This function can't be called in restricted-execution mode.

    抛出

    如果由于无效参数或拼图配置导致生成失败，则抛出异常。 如果放置位置包含世界边界以外的方块，则抛出异常。

    PlaceJigsawError

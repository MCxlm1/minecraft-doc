类 SoundInstance

表示一个已播放声音的句柄。在 声音播放期间，需要使用该句柄来控制声音 （例如调用 stop、setVolume、setPitch、 fade 或 seekTo）。无限循环的声音（通过 loop: -1 启动）会在最后一个 SoundInstance 引用被丢弃时自动停止； 只要声音应继续播放，请保留该句柄。

方法

fade

  • fade(duration, targetVolume): void
  • beta

    参数

    • duration: number

      淡变持续时长（秒）。必须为非负值。 最小值：0

    • targetVolume: number

      要淡变到的音量。必须为非负值。 最小值：0

    返回 void

    备注

    在指定持续时间内，将此声音实例从当前音量淡变到目标音量。 若要从静音开始淡入，请先调用 setVolume(0.0)；若要淡出， 请传入目标音量 0.0。

    This function can't be called in restricted-execution mode.

seekTo

  • seekTo(seconds): void
  • beta

    参数

    • seconds: number

      要跳转到的位置（秒）。必须为非负值。 范围：[0, 107374184]

    返回 void

    备注

    设置此声音实例的播放位置。

    抛出

    如果 seconds 为负，或声音具有已知时长且 seconds 大于该时长，则抛出异常。

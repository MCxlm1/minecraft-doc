类 ItemDurabilityComponent

当物品上存在此组件时，该物品会在使用过程中承受伤害。 请注意，此组件仅适用于数据驱动的物品。

示例: giveHurtDiamondSword.ts

import {
  world,
  ItemStack,
  EntityInventoryComponent,
  EntityComponentTypes,
  ItemComponentTypes,
  ItemDurabilityComponent,
  DimensionLocation,
} from '@minecraft/server';
import { MinecraftItemTypes } from '@minecraft/vanilla-data';

function giveHurtDiamondSword(targetLocation: DimensionLocation) {
  const hurtDiamondSword = new ItemStack(MinecraftItemTypes.DiamondSword);

  const durabilityComponent = hurtDiamondSword.getComponent(ItemComponentTypes.Durability) as ItemDurabilityComponent;

  if (durabilityComponent !== undefined) {
    durabilityComponent.damage = durabilityComponent.maxDurability / 2;
  }

  for (const player of world.getAllPlayers()) {
    const inventory = player.getComponent(EntityComponentTypes.Inventory) as EntityInventoryComponent;
    if (inventory && inventory.container) {
      inventory.container.addItem(hurtDiamondSword);
    }
  }
}

damage

damage: number

备注

返回此特定物品当前的伤害等级。

This property can't be edited in restricted-execution mode.

只读isValid

isValid: boolean

备注

返回该组件是否有效。如果其所有者有效，并且满足该组件所需的任何额外验证， 则该组件被视为有效。

继承自 ItemComponent.isValid

只读maxDurability

maxDurability: number

备注

表示此物品在损坏之前可承受的伤害量。

抛出

此属性被访问时可能会抛出错误。

只读typeId

typeId: string

备注

组件的标识符。

继承自 ItemComponent.typeId

unbreakable

unbreakable: boolean

备注

该物品是否会损坏或丢失耐久度。设置为 true 会暂时移除物品的耐久度 HUD， 并冻结物品的耐久度损失。

This property can't be edited in restricted-execution mode.

方法

getDamageChance

  • getDamageChance(unbreakingEnchantmentLevel?): number

  • 参数

    • 可选unbreakingEnchantmentLevel: number

      计算受损几率时要考虑的耐久附魔等级。 传入的 unbreaking 参数必须在 [0, 3] 范围内。 默认值：0 范围：[0, 3]

    返回 number

    返回该物品受损的最大几率。

    备注

    返回在给定的耐久附魔等级下，使用 damageRange 属性计算出的该物品受损的最大几率。

    This function can't be called in restricted-execution mode.

    抛出

    当 unbreakingEnchantmentLevel 超出 [0, 3] 范围时，此函数会抛出错误。

getDamageChanceRange

  • getDamageChanceRange(): NumberRange

  • 返回 NumberRange

    返回用于计算损坏几率的数字范围。

    备注

    用于计算物品损坏几率的一组数字范围，损坏几率将落在此范围内。

    This function can't be called in restricted-execution mode.

    抛出

    此函数可能抛出错误。

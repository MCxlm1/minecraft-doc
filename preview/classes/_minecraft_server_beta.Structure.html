类 Structure

表示一个已加载的结构模板（.mcstructure 文件）。 可以使用 /structure 命令或 StructureManager API 将结构放置到世界中。

属性

只读id

id: string

备注

结构的名称。标识符必须包含命名空间。 对于通过 /structure 命令或结构方块创建的结构， 此命名空间默认为 "mystructure"。

只读isValid

isValid: boolean

备注

返回结构是否有效。如果结构被删除， 则可能变为无效。

只读size

size: Vector3

备注

结构的尺寸。例如，单个方块结构的尺寸为 {x:1, y:1, z:1}

抛出

此属性在使用时可能抛出错误。

InvalidStructureError

方法

getBlockPermutation

  • getBlockPermutation(location): BlockPermutation

  • 参数

    • location: Vector3

      相对于 Structure 原点的方块位置。

    返回 BlockPermutation

    返回一个 BlockPermutation。如果指定位置不存在方块， 则返回 undefined。

    备注

    返回一个 BlockPermutation，表示 Structure 中 指定位置所包含的方块。

    抛出

    如果位置超出结构边界则抛出异常。 如果 Structure 已被删除则抛出异常。

    InvalidStructureError

getIsWaterlogged

  • getIsWaterlogged(location): boolean

  • 参数

    • location: Vector3

      相对于 Structure 原点的方块位置。

    返回 boolean

    返回指定位置的方块是否含水。 如果指定位置不存在方块，则返回 false。

    备注

    返回指定位置的方块是否含水。

    抛出

    如果位置超出结构边界则抛出异常。 如果 Structure 已被删除则抛出异常。

saveAs

  • saveAs(identifier, saveMode?): Structure

  • 参数

    • identifier: string

      新创建 Structure 的名称。

    • 可选saveMode: StructureSaveMode

      决定如何保存 Structure。默认为保存到世界。 默认值：1

    返回 Structure

    返回新创建的结构。

    备注

    创建一个 Structure 的副本，并使用新名称保存。

    此函数无法在受限执行模式中调用。

    抛出

    如果标识符无效则抛出异常。有效标识符必须 包含命名空间且必须唯一。 如果 Structure 已被删除则抛出异常。

    minecraftcommon.EngineError

    minecraftcommon.InvalidArgumentError

    InvalidStructureError

saveToWorld

  • saveToWorld(): void

  • 返回 void

    备注

    将修改后的 Structure 保存到世界文件。

    此函数无法在受限执行模式中调用。

    抛出

    如果 Structure 已被删除则抛出异常。

    InvalidStructureError

setBlockPermutation

  • setBlockPermutation(location, blockPermutation?, waterlogged?): void

  • 参数

    • location: Vector3

      相对于 Structure 原点的方块位置。

    • 可选blockPermutation: BlockPermutation

      要设置的 BlockPermutation。 默认值：null

    • 可选waterlogged: boolean

      指定方块是否应含水。空气和未定义的方块 不能为含水状态。 默认值：false

    返回 void

    备注

    在 Structure 中设置 BlockPermutation。

    此函数无法在受限执行模式中调用。

    抛出

    如果方块类型为 StructureVoid 则抛出异常。 如果方块为 undefined 且 waterlogged 设置为 true 则抛出异常。 如果方块为空气且 waterlogged 设置为 true 则抛出异常。 如果位置超出结构边界则抛出异常。 如果 Structure 已被删除则抛出异常。

    minecraftcommon.InvalidArgumentError

    InvalidStructureError

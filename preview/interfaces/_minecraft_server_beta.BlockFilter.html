接口 BlockFilter

基于类型、标签或置换来包含或排除方块的选项。如果未添加任何包含选项， 将选择所有未被排除选项拒绝的方块。如果添加了至少一个包含选项， 方块必须匹配其中一个包含选项才不会被拒绝。

interface BlockFilter {
    excludePermutations?: BlockPermutation[];
    excludeTags?: string[];
    excludeTypes?: string[];
    includePermutations?: BlockPermutation[];
    includeTags?: string[];
    includeTypes?: string[];
}

接口 StructurePlaceOptions

为 StructureManager.place 提供额外选项。

interface StructurePlaceOptions {
    animationMode?: StructureAnimationMode;
    animationSeconds?: number;
    includeBlocks?: boolean;
    includeEntities?: boolean;
    integrity?: number;
    integritySeed?: string;
    mirror?: StructureMirrorAxis;
    rotation?: StructureRotation;
    waterlogged?: boolean;
}

属性

可选animationMode

animationMode?: StructureAnimationMode

备注

放置结构时应如何播放动画。

可选animationSeconds

animationSeconds?: number

备注

动画播放所需的秒数。

可选includeBlocks

includeBlocks?: boolean

备注

结构中是否包含方块。默认为 true。

可选includeEntities

includeEntities?: boolean

备注

结构中是否包含实体。默认为 true。

可选integrity

integrity?: number

备注

应放置方块的百分比。值为 1 时将放置 100% 的方块，值为 0 时不放置 任何方块。方块将基于 StructurePlaceOptions.integritySeed 随机选择。

可选integritySeed

integritySeed?: string

备注

决定哪些方块会被随机选择放置的种子。默认为随机种子。

可选mirror

mirror?: StructureMirrorAxis

备注

放置时结构应沿哪些轴进行镜像。默认为 StructureMirrorAxis.None。

可选rotation

rotation?: StructureRotation

备注

放置时结构应如何旋转。默认为 AxisAlignedRotation.None。

可选waterlogged

waterlogged?: boolean

备注

放置时结构是否应含水。默认为 false。如果为 true，方块放置在水中时将变为含水状态。

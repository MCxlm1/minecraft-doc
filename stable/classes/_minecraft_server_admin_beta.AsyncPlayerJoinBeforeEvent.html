类 AsyncPlayerJoinBeforeEvent

The data available before a player joins the world.

索引

属性

name persistentId splitScreenSlot?

方法

allowJoin disallowJoin disconnect isValid

属性

只读name

name: string

备注

The player's name

只读persistentId

persistentId: string

备注

An identifier that can be used to identify a player across sessions.

可选 只读splitScreenSlot

splitScreenSlot?: PlayerSplitScreenSlot

备注

The split screen slot of the joining player or undefined if the player is not in a split screen session.

方法

allowJoin

  • allowJoin(): void

  • 返回 void

    备注

    Call this to explicitly allow the player to join the server. This is useful when player joining is disabled (allow-player-joining is set to false when playing on dedicated server).

    抛出

    This function can throw errors.

    DisconnectedError

disallowJoin

  • disallowJoin(reason?): void

  • 参数

    • 可选reason: string

    返回 void

    备注

    Call this to disallow the player from joining the server. This is useful for preventing unauthorized access to the server.

    抛出

    This function can throw errors.

    DisconnectedError

disconnect

  • disconnect(reason?): void

  • 参数

    • 可选reason: string

    返回 void

    备注

    Deprecated - use AsyncPlayerJoinBeforeEvent.disallowJoin instead. Call this to disconnect a player. They will be allowed to try to join again. They will be allowed to try to join again after being disconnected.

    抛出

    This function can throw errors.

    DisconnectedError

isValid

  • isValid(): boolean

  • 返回 boolean

    备注

    Will return true if the player is still waiting to join the world. If they disconnect then it will return false.

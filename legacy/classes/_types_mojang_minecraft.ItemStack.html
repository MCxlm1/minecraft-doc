类 ItemStack

Symbol

ItemStack

Description

定义一组物品的集合。

构造函数

constructor

  • new ItemStack(itemType, amount?, data?): ItemStack

  • 参数

    • itemType: ItemType

      要创建的物品类型。

    • 可选amount: number

      堆叠中的物品数量，介于 1 到 64 之间。

    • 可选data: number

      用于创建物品的数据值，默认为 0。

    返回 ItemStack

    备注

    创建新的物品堆叠实例供世界中使用。

属性

amount

amount: number

堆叠中物品的数量。有效值范围为 0 到 64。

data

data: number

用于配置物品不同状态的数据值。

只读id

id: string

物品堆叠类型的标识符。如果未指定命名空间，则默认使用 'minecraft:'。 示例包括 'wheat' 或 'apple'。

可选nameTag

nameTag?: string

此物品堆叠的自定义名称。

方法

getComponent

  • getComponent(componentId): any

  • 参数

    • componentId: string

      要获取的组件标识符。

    返回 any

    如果物品堆叠上存在该组件则返回组件对象，否则返回 undefined。

    备注

    获取物品堆叠的组件（表示附加能力）。

getComponents

  • getComponents(): any[]

  • 返回 any[]

    备注

    返回此物品堆叠上存在且 API 支持的所有组件。

getLore

  • getLore(): string[]

  • 返回 string[]

    备注

    获取物品堆叠的 lore 值（辅助显示字符串）。

hasComponent

  • hasComponent(componentId): boolean

  • 参数

    • componentId: string

      要检查的组件标识符。

    返回 boolean

    备注

    检查指定组件是否存在于物品堆叠上。

setLore

  • setLore(loreList): void

  • 参数

    • loreList: string[]

      lore 字符串列表。

    返回 void

    备注

    设置物品堆叠的 lore 值（辅助显示字符串）。

triggerEvent

  • triggerEvent(eventName): void

  • 参数

    • eventName: string

      要触发的物品类型事件名称。

    返回 void

    备注

    触发物品类型事件。对于自定义物品，定义中定义了一些事件用于关键物品行为。
